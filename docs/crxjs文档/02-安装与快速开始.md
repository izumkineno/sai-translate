# 02 — 安装与快速开始（90 秒）

> 来源：`packages/vite-plugin-docs/docs/getting-started/**`（Solid / React / Vue / Vanilla 全量）、`_install-extension.md`、 `_dev-basics-intro.md`、 `README` 的 Create 分支
> 适用：本项目模板 `Solid + Vite + CRXJS`（`vite 8.0.0 + @crxjs/vite-plugin 2.4.0 + vite-plugin-solid 2.11.11`）

## 1. 环境要求

- Node ≥ 14（Vite 3+），实测本模板使用 Bun/Node 均可，`package.json#type: "module"` **必须**存在，否则 `vite.config.ts` 无法被 ESM 加载（`docs/getting-started/solid/00-create-project.md` TIP）
- 浏览器：Chrome / Edge（Chromium），`chrome://extensions` 开启 **Developer mode**
- 框架 HMR 兼容性：`@vitejs/plugin-react` ✅ / `@vite/plugin-react-swc` ❌（与 CRXJS content-script HMR 冲突，见 `_create-project-tabs.mdx`）

## 2. 两种创建方式

### 方式 A — 官方脚手架（推荐新项目）

```sh
npm create crxjs@latest
# 按提示选 solid / react / vue / vanilla-js
# ⚠️ 必须带 @latest，否则命中缓存旧版（README IMPORTANT）
```

### 方式 B — 在现有 Vite 项目中接入（本模板即此方式）

```sh
npm i -D @crxjs/vite-plugin   # 本模板已在 devDeps: 2.4.0
npm i vite-plugin-solid        # Solid 专用
```

`vite.config.ts` 最小接入（本项目实测可用，见 `vite.config.ts`）：

```ts
import { crx } from '@crxjs/vite-plugin'
import { defineConfig } from 'vite'
import solid from 'vite-plugin-solid'
import manifest from './manifest.config.ts'

export default defineConfig({
  plugins: [solid(), crx({ manifest })],
  server: { cors: { origin: [/chrome-extension:\/\//] } }, // 2.6.0+ 已自动放行，显式声明更稳
})
```

`manifest.config.ts`（TypeScript 版，带自动补全）：

```ts
import { defineManifest } from '@crxjs/vite-plugin'
import pkg from './package.json'
export default defineManifest({
  manifest_version: 3,
  name: pkg.name,
  version: pkg.version,
  action: { default_popup: 'src/popup/index.html' },
})
```

> 亦可直接用 `manifest.json`，插件同时支持 `json / js / ts`（`concepts/00-manifest.md#Extension Manifest`）。

## 3. 脚本约定

```json
{
  "scripts": {
    "dev": "vite",                    // 开发：启动 fileWriter + HMR，产物在 dist/
    "build": "tsc -b && vite build", // 生产：Rollup 打包 + zip-pack
    "preview": "vite preview"
  }
}
```

## 4. 首次开发构建

```sh
npm run dev
# 输出形如：dist/ 已生成 service-worker-loader.js / manifest.json / popup.html ...
```

打开 `chrome://extensions` → 开发者模式 **ON** → 拖拽 `dist/` 到页面（或「加载已解压的扩展程序」选 `dist`）→ 扩展图标出现在工具栏（图标为扩展名首字母或 `icons[48]`）。

> 详见 `_install-extension.md`：Chrome 开关在右上角，Edge 在左侧边栏；图标默认为名称首字母。

## 5. 调试 HMR（以 Solid popup 为例）

1. 右键扩展图标 → **Inspect popup window**（保持弹窗常驻）
2. 修改 `src/popup/App.tsx` 或 `src/popup/App.css` → 保存
3. 观察：popup **不刷新整页**，仅热更（`docs/getting-started/solid/01-dev-basics.md#Profit with Vite HMR`）
4. 若改 `src/content/main.ts` → 宿主页（`matches` 匹配的页面）content script 热更，**无需刷新宿主页**（`contentScripts.ts` + `fileWriter.ts` 联动）

小技巧：给 popup 加 `min-width: 350px` 可避免默认过窄（官方示例 `App.module.css`）。

## 6. 生产构建与发布

```sh
npm run build
# 产物：dist/ + release/crx-sai-translate-1.0.0.zip（由 vite-plugin-zip-pack 生成）
```

`vite-plugin-zip-pack` 配置（本模板 `vite.config.ts:18`）：

```ts
zip({ outDir: 'release', outFileName: `crx-${name}-${version}.zip` })
```

可直接上传 Chrome Web Store。

## 7. Solid 专用注意

- `vite-plugin-solid` 需在 `crx()` 之前注册（插件顺序敏感，`pluginContentScriptsIife()` 必须早于 manifest 插件，见 `src/node/index.ts`）
- `tsconfig.app.json` 需 `jsx: preserve` + `jsxImportSource: solid-js` + `types: ["vite/client", "@crxjs/vite-plugin/client", "chrome"]`
- 内容脚本挂载需自建容器（见 `03-...` 与 `05-...`）：

```tsx
const root = document.createElement('div')
root.id = 'crx-root'
document.body.append(root)
render(() => <App />, root)
```
