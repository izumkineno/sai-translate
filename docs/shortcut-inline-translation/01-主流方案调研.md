# 主流方案调研 — 快捷键翻译 + 行下嵌入

> 覆盖：沉浸式翻译 / 沙拉查词 Saladict / 划词翻译 / Bob / DeepL / Google Translate 扩展  
> 目标：回答“快捷键如何触发翻译”与“翻译结果如何嵌入到目标文本下方”两种机制。

## 1. 结论先行

| 维度 | 主流共识 |
|---|---|
| 快捷键触发 | **双轨**：`manifest.commands`（Chrome 原生快捷键，可全局、可自定义）+ `content_scripts` 内监听 `keydown`（页内快捷键、双击/三击、可配置） |
| 选词获取 | `window.getSelection()` + `Range`，失败回退 `document.activeElement.value.substring(selectionStart, selectionEnd)`（输入框） |
| 行下嵌入 | **块级锚点 + 兄弟节点插入**，容器用 `Shadow DOM` 或 `scoped class` 隔离样式，`MutationObserver` 防网页重绘丢失 |
| 样式隔离 | 沉浸式/Saladict 均用 `attachShadow({mode:'open'})`，避免页面 CSS 污染与被页面 JS 误删 |
| 翻译通道 | `content → background(service_worker) → LLM API`，Key 只存 `chrome.storage`，content 永不直连外网 |

## 2. 快捷键实现的两条正交路径

### 2.1 `chrome.commands`（推荐作主快捷键）

```json
// manifest.json
{
  "commands": {
    "translate-selection": {
      "suggested_key": { "default": "Alt+Shift+T", "mac": "Alt+Shift+T" },
      "description": "翻译当前选中文本并在下方展示"
    },
    "translate-page-block": {
      "suggested_key": { "default": "Alt+Shift+Y" },
      "description": "翻译当前段落/整页可见块"
    }
  }
}
```

- **触发位置**：`background/service_worker` 监听 `chrome.commands.onCommand`
- **优点**：不与网页 `keydown` 冲突、用户可在 `chrome://extensions/shortcuts` 自行改键、焦点不在页面时也能触发
- **缺点**：可注册数量有限（Chrome 限制 4 条带 `suggested_key`）、组合键受限（必须含 `Ctrl/Alt/Command` + `Shift`）、无法监听“双击 Ctrl”等手势
- **典型使用者**：沉浸式翻译（`Alt+A` 双语切换）、Saladict（`Alt+S` 划词）、Google Translate（`Alt+Shift+T`）

### 2.2 `content_scripts` 内 `keydown` 监听（作辅助/自定义快捷键）

```ts
// src/content/shortcut.ts
const HOTKEY = 'KeyQ' // Alt+Q，可存 storage 让用户改
window.addEventListener('keydown', (e) => {
  if (e.altKey && !e.shiftKey && !e.ctrlKey && e.code === HOTKEY) {
    e.preventDefault()
    handleTranslateSelection()
  }
  // 双击 Ctrl：记录时间戳，300ms 内按两次
})
```

- **优点**：任意键位、可实现“按两下 Ctrl 翻译”“选中即显”等细粒度交互
- **缺点**：与网页快捷键冲突、iframe/输入框内需特殊放行、`content` 未注入的页（`chrome://`）无法生效
- **典型使用者**：Bob 的 `⌥+D` 划词、沉浸式翻译的“鼠标悬停+快捷键”

### 2.3 主流的混合策略

| 扩展 | 策略 |
|---|---|
| **沉浸式翻译** | `commands` 负责整页/段落翻译；页内 `keydown` 负责 hover 段落翻译；两者共享同一 `translate()` 通道 |
| **Saladict** | `commands` 触发划词弹窗；页内监听 `mouseup` + 300ms 判定是否“划词完成”再弹词典；快捷键可在设置页改并写 `storage` 同步到 content |
| **划词翻译（hcfy）** | `mouseup` 后在选区右下角挂小图标，点图标或按 `Alt+Shift+C` 触发翻译 |
| **Google Translate** | `commands` + 右键菜单 `contextMenus`，翻译结果先弹 mini-popup，点“在下方显示”再行下嵌入 |

**给 sai-translate 的建议**：抄沉浸式/Saladict 的混合——`commands` 作兜底 + `content keydown` 作可配置快捷键，配置页存 `chrome.storage.local`，`content` 首次注入时读取。

## 3. 行下嵌入（Inline-below）的主流模式

### 3.1 三种嵌入形态

```
形态 A — 替换式：  原文 -> 译文（丢原文）
形态 B — 行下块：  原文段落
                  ┌─────────────┐
                  │ 译文块（新兄弟节点）│  <- 主流，沉浸式/bob 用此
                  └─────────────┘
形态 C — 浮层式：  选区旁 absolute 弹窗（Saladict/Google 默认）
```

用户诉求是**形态 B：目标文本正下方插入块**，与沉浸式翻译“双语对照”一致。

### 3.2 锚点定位算法（沉浸式翻译精髓）

```ts
function findBlockAnchor(range: Range): HTMLElement {
  let node: Node | null = range.commonAncestorContainer
  if (node.nodeType === Node.TEXT_NODE) node = node.parentElement
  let el = node as HTMLElement
  // 向上找块级容器
  while (el && !isBlock(el) && el !== document.body) {
    el = el.parentElement!
  }
  // 特殊：表格/列表项/代码块直接用自身
  return el ?? (range.commonAncestorContainer as HTMLElement)
}
function isBlock(el: HTMLElement): boolean {
  const d = getComputedStyle(el).display
  return d === 'block' || d === 'flex' || d === 'grid' || d === 'list-item' || el.tagName === 'P'
}
```

- 沉浸式翻译对 `<p>、<div>、<li>、<h1..h6>、<blockquote>、<pre>` 逐级打分选择最佳锚点
- 选区跨多块时，拆句按 `Range` 的 `getClientRects()` 分段，逐块下方各插一条

### 3.3 插入与样式隔离

```ts
function injectBelow(anchor: HTMLElement, html: string) {
  const wrapper = document.createElement('div')
  wrapper.className = 'sai-translate-inline'
  wrapper.dataset.sai = '1'
  // 关键：Shadow DOM 隔离，避免页面 CSS 把译文染成 display:none
  const shadow = wrapper.attachShadow({ mode: 'open' })
  const style = document.createElement('style')
  style.textContent = `
    :host { display:block; margin:6px 0 10px; }
    .box { background:#fff; border:1px solid #e5e7eb; border-radius:8px;
           padding:10px 12px; font-size:13px; line-height:1.6; color:#1f2937;
           box-shadow:0 4px 16px rgba(0,0,0,.08); }
  `
  const box = document.createElement('div')
  box.className = 'box'
  box.textContent = html
  shadow.append(style, box)

  // 复用：若已有一条则更新而非重插
  const prev = anchor.nextElementSibling as HTMLElement | null
  if (prev?.dataset.sai === '1') prev.replaceWith(wrapper)
  else anchor.after(wrapper)
  return wrapper
}
```

| 隔离手段 | 效果 | 取舍 |
|---|---|---|
| `attachShadow` | 最佳，完全隔离 `* {}` 污染 | 事件需穿透，复制需 `shadowRoot` 内处理 |
| `iframe` | 隔离最彻底 | 体积大、高度自适应难 |
| `scoped class + :where` | 最轻 | 易被 `!important` 覆盖 |

**主流选择**：沉浸式 6.x 后全切 Shadow DOM；Saladict 对译文块用 Shadow DOM，对词典弹窗用 `iframe`。

### 3.4 选中文本提取（含输入框/可编辑区）

```ts
function getSelectedText(): { text: string; range: Range | null } {
  const sel = window.getSelection()
  if (sel && sel.rangeCount && !sel.isCollapsed) {
    const range = sel.getRangeAt(0).cloneRange()
    return { text: sel.toString().trim(), range }
  }
  // 回退：input/textarea/contenteditable
  const ae = document.activeElement as HTMLInputElement | null
  if (ae && (ae.tagName === 'TEXTAREA' || ae.tagName === 'INPUT')) {
    const { selectionStart, selectionEnd, value } = ae
    if (selectionStart != null && selectionEnd != null && selectionStart !== selectionEnd) {
      return { text: value.slice(selectionStart, selectionEnd).trim(), range: null }
    }
  }
  return { text: '', range: null }
}
```

沉浸式/Saladict 还会：
- 过滤纯符号/URL/过短文本（<2 字符不译）
- `normalizeWhitespace` 合并多空白、去 `&nbsp;`

### 3.5 生命周期与防丢失

- `MutationObserver` 监听 `anchor.parentNode`，若译文块被页面框架重渲染移除，延迟 200ms 重新 `after()` 插入
- 滚动/路由切换（SPA `history.pushState`）时清理旧块
- 全局 `Map<anchor, wrapper>` 防重复、支持“再按一次快捷键隐藏/重译”

## 4. 通信与权限（MV3）

```
[content] --(1) getSelectedText()--> [content]
    | --(2) chrome.runtime.sendMessage({type:'TRANSLATE', text, target})--> [background SW]
    |                                                                     | 读 storage 拿 Key/Model
    |                                                                     | fetch https://api.openai.com/v1/chat/completions
    | <--(3) {ok, translated}----------------------------------------------|
    | --(4) injectBelow(anchor, translated) --> [DOM]
```

- `background` 存 `chrome.storage.local` 的 `ModelSource[]`，与现有 `src/popup/store/models.ts` 同源
- `content` 不直接 `fetch` 外网：避免 CORS + 暴露 Key；`background` 统一走 `host_permissions: https://*/*`
- 失败回退：若 SW 休眠未响应，`content` 可直连（需 `host_permissions` 覆盖）
