## 9. 风险与回退

| 风险 | 缓解 |
|---|---|
| 样式被页面全局 `!important` 覆盖 | Shadow DOM 已隔离；极端页再加 `all: initial` |
| 与页面 `Alt+Q` 冲突 | 设置页允许改键，默认提供“禁用页内快捷键”开关 |
| SW 休眠导致首次翻译超时 | content 本地 `fetch` 回退（需 host_permissions） |
| 选中锚点判断错误（表格/代码块） | `isBlock` 白名单加 `TABLE/TR/TD/PRE/CODE/BLOCKQUOTE` |
